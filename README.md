## En resumen

- **Qué hacemos:** diseño y desarrollo de landing pages modernas, rápidas y mobile-first; hosteo facilitado para negocios cercanos a Gualeguaychú.
- **Base:** Gualeguaychú, Entre Ríos, Argentina. Trabajo 100% remoto para Argentina y el resto del mundo.
- **Stack:** HTML, CSS, JavaScript, TypeScript, React, Next.js, Express.js.
- **Diferencial:** IA aplicada como herramienta de potencia (research, prototipado, refactors), dirigida por humanos para mantener arquitectura y calidad.
